# 🏡 Airbnb Website – MEN Stack

A backend Airbnb clone built using the MEN stack (MongoDB, Express.js, Node.js), featuring user authentication, property listings, and a booking system.  
Includes RESTful APIs for property management, search, and reservations.

---

## 🔧 Features

- User registration and JWT-based authentication
- Create, read, update, delete (CRUD) property listings
- Booking system with date validation
- Search and filter by location, dates, and guests
- Modular and scalable code structure

---

## 🚀 Tech Stack

- **MongoDB** – Database for storing users, listings, and bookings  
- **Express.js** – Web framework for API endpoints  
- **Node.js** – Server-side JavaScript runtime  
- **Mongoose** – ODM for schema modeling and validation
